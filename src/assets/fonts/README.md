# Fonts

Subsets of two SIL Open Font License typefaces (licenses alongside):

- **Newsreader** (Production Type): static 400, 500, 600 and 400 italic, cut from the variable font.
- **IBM Plex Sans** (IBM): 400, 500, 600.

All files are reduced to the characters this page uses (Basic Latin, Latin-1, common punctuation, arrows and a few math and geometric symbols) to keep first paint fast. They were made with `fonttools` (`pyftsubset` and `varLib.instancer`) from the `@fontsource` releases.
